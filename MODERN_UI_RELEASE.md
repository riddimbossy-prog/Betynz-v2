# Betynz Modern UI Release

This release keeps the unified SportyBet API and all prediction engines unchanged while replacing the presentation layer with a premium dark prediction interface.

## Visual changes
- Official silver/orange Betynz logo integrated into the sidebar and admin area.
- Black, graphite and orange lightning design system.
- Modern KPI cards, consensus spotlight, fixture rows and match-intelligence dialog.
- Refined odds cards, filters, route badges and active engine states.
- Responsive layouts retained for desktop, tablet, phone and Samsung Z Fold.

## Functional safety
- Existing HTML IDs and JavaScript hooks were preserved.
- SportyBet remains authoritative for fixtures, markets, live scores and results; API-Football supplies engine statistics and official visuals.
- Market Route, PPG Route, Convergence and Consensus logic are unchanged.
- One root render.yaml and one Render service remain enforced.
