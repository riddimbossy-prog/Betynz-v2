# Betynz v5.0.6 responsive validation

Source assertions cover phone, Z Fold cover, Z Fold inner, tablet, laptop and wide desktop layouts.

The Momentum page uses the same responsive route-card system as the existing engines. Ordered form badges wrap safely on narrow screens, controls become touch-friendly, and no horizontal page scroll is introduced.

The rolling wins carousel collapses to a compact ticker on narrow screens. Launch motion, card tilt and continuous tickers stop under `prefers-reduced-motion: reduce`.
