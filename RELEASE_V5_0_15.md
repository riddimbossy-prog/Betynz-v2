# Betynz v5.0.15 — Atlas UI Readability Edition

This release is a presentation-only repair for the Atlas Streak Value Engine. Prediction rules, Stats API thresholds, xG/SOT confirmation logic, seven-engine Consensus and provider queues are unchanged.

## Atlas UI changes
- Repairs the inherited four-column evidence grid that compressed team statistics vertically.
- Rebuilds each team profile into readable Strength, PPG, Goals For, Goals Against and streak blocks.
- Adds a compact Market filter for Team Goals, Match Goals and Result Markets.
- Uses one-column pick cards on normal laptop/tablet widths and two columns only on wide displays.
- Makes xG, SOT and Atlas score clearly readable without exposing private thresholds.
- Improves phone and Z Fold layouts while preserving the Betynz black/silver/white/orange palette.
- Keeps motion light: short pick reveal and analysis pulse only.

No Supabase migration is required from v5.0.14.
