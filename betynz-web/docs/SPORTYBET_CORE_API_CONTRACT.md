# SportyBet Core API contract

Betynz Web sends its private key server-side and consumes:

```text
search_matches?date={date}&page=1&page_size=100
get_fixture_stats?event_id=...
get_team_history?...
get_team_streaks?...
get_competition_stats?...
live?date=...
results?date=...
events?event_id=...
```

Fixture responses must preserve real SportyBet identity, kickoff, league, teams, status, score, offered prices and full market rows. Missing values remain unavailable; neither service manufactures evidence.

The web server sanitizes all public responses and never exposes the private API key or upstream configuration.
