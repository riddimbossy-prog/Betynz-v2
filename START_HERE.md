# Start here — Betynz v5.0.13

1. Extract the ZIP.
2. Keep only the hidden `.git` folder in the existing local repository, then copy every extracted file into the repository root.
3. Commit: `Betynz v5.0.13 fast engine consensus lane`.
4. Push through GitHub Desktop.
5. In Render choose **Manual Deploy → Clear build cache & deploy**.
6. Open `/api/health` and confirm version `5.0.13`.
7. Hard-refresh the website with `Ctrl + Shift + R`.

No Supabase migration is required when upgrading from v5.0.12.
