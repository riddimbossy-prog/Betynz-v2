# Betynz v5.0.15 Start Here

This is a UI-only upgrade over v5.0.14. No engine thresholds, provider keys, Render architecture or Supabase tables changed.

1. Replace the repository contents with this release.
2. Keep your existing Render secrets, including API_FOOTBALL_KEY and STATS_API_KEY.
3. Push to GitHub.
4. In Render choose Manual Deploy -> Clear build cache & deploy.
5. Hard refresh once with Ctrl+Shift+R.

No Supabase migration is required when upgrading from v5.0.14.
